01 / Getting started

Introduction #

Web4 is the next version of the web. These docs cover everything you need to build on it: the command line, the SDK and the REST API.

If you’ve built on web3 before, good news: none of it applies here.

$ clit

Web4 CLIT

Create, run and deploy from your terminal.

SDKs

JavaScript, Python and Rust (soon).

REST API

Web4 goes public soon. But don’t get too excited about Web5!

Install #

The Web4 CLIT comes preinstalled on every computer. It just isn’t turned on yet. To check your version:

Terminal
$ web4 --version

If you see command not found, that’s the soon part.

Quickstart #

From zero to mainnet in four steps.

  1. Create a project

    Terminal
    $ web4 init my-dapp
$ cd my-dapp

  2. Start your node

    Your node is the whole network. Be nice to it.

    Terminal
    $ web4 node start
✓ single node blockchain running on localhost:4444
✓ consensus reached (1/1 nodes agree)

  3. Mint something

    Terminal
    $ web4 mint
✓ minted super turbo mega ultra NFT #0004

  4. Ship it

    Terminal
    $ web4 deploy --prod
✓ deployed to 1/1 nodes

That’s it. You’re upgraded.

Single Node Blockchain #

Traditional blockchains ask thousands of nodes to agree on every transaction. Web4 asks one. It has never said no.

Proof of no proof

Think of a number. The node confirms it and you have it.

wallet.js
const balance = await web4.wallet.balance(1_000_000);

Super Turbo Mega Ultra NFTs #

STMU NFTs are NFTs, but more. Every token follows the WRC-4444 standard and ships at one level: the next.

nft.json
{
  "id": "0004",
  "standard": "WRC-4444",
  "level": "next",
  "turbo": true
}

Warning

STMU NFTs run hot. Some collectors report theirs went up in flames overnight. This is expected.

03 / Reference

SDK #

The SDK ships with the CLIT, so it’s preinstalled too. Pick a language:

import { Web4 } from "web4";

const web4 = new Web4({ network: "mainnet" });

// Proof of no proof: think of a number and have it
const wallet = await web4.wallet.create();
await wallet.balance(1_000_000);

// Mint a super turbo mega ultra NFT
const nft = await web4.nft.mint({ level: "next" });

console.log(nft.level); // "next"
from web4 import Web4

web4 = Web4(network="mainnet")

# Proof of no proof: think of a number and have it
wallet = web4.wallet.create()
wallet.balance(1_000_000)

# Mint a super turbo mega ultra NFT
nft = web4.nft.mint(level="next")

print(nft.level)  # "next"

REST API #

Errors #

Every error has a code, a name and a suggested fix. The fix is usually “wait”.

CodeNameMeaningFix
W4-000OKEverything is supercharged.Retry until it fails.
W4-001SOONNot yet.Wait.
W4-003STILL_ON_WEB3Your client is still on web3.Accelerate.
W4-422NOT_A_NUMBERYou thought of something that isn’t a number.Think harder.
W4-425TOO_EARLYYou asked for Web5.Wait. Longer.
W4-500OVERCHARGEDToo supercharged.Add another turbo.
W4-999FLAMESYour NFT went up in flames. This is expected.Wait for it to cool down. It won’t.
